# DUMBER — 12 秒宣传片设计稿 v2

## 核心修正

这不是“让 feed 更刺激”的功能演示，而是一段主动沉入信息流的体验。

主句：`LET THE FEED PULL YOU IN.`

上一版的六张独立画面收束为一个连续空间：原生 HTML/CSS 仿写的 X 信息流始终占满画面，镜头、扫描球、虹彩和 meme 都在同一次滚动里完成。除了产品名 `DUMBER`，全片不做讽刺提示，也不跳出沉浸感评价内容。

## 成片规格

- 12 秒，1920×1080，30 fps
- X / GitHub / 产品首页
- 无旁白，极少英文叠字
- 一个完全可导演的 X 页面 DOM + 确定性图形与叠字
- 黑色不是背景板，而是 X 原生界面中的空间

## 连续分镜

| 时间 | 状态 | 画面与动作 | 文案 | 声音 |
|---|---|---|---|---|

## 四张英雄帧

1. **00.00 — Already inside**：拟真未精选 feed 满屏；扫描胶囊已进入，观众没有“先看广告”的退出机会。
2. **02.60 — The pull**：同一画面继续下滚；Thinking Orb 的点阵丝带在球内明显扭转，目标帖即将进入锁定位置。
3. **05.20 — Caught**：精选卡片占据画面约 70%，完整边框和极短多色情绪词成为两个层次的焦点。
4. **10.80 — Stay in it**：feed 仍在背后移动；DUMBER 与 `LET THE FEED PULL YOU IN.` 是覆盖层，而不是离开产品后的尾卡。

预览见 `STORYBOARD.png`。

## 虹彩的叙事职责

- 在球体中：AI 正在工作。
- 球体脉冲：模型完成第一次命中。
- 绕住卡片：模型已完成第一步选择。
- 进入短词：模型已完成第二步文案处理。
- 收束为下划线：DUMBER 接管并维持这次沉浸。

球体、边框、文字与尾卡共用同一套霓虹色序；不使用跨越页面的连接线制造虚假的连续性。

## 文字与 meme

- 主句只在 9.8 秒后完整出现，读完需要约 1.2 秒。
- 使用 Archivo Black；`DUMBER` 92–116 px，主句 56–68 px，字距 `-0.04em`。
- 计数与技术小字使用 IBM Plex Mono，并启用等宽数字。
- meme 是产品人格的瞬时反射，不是独立段落；只用项目已有闭眼头像。
- 不出现 `this one.`、`risk`、`focus`、`control`、`better for you` 等解释。

## 转场与镜头

- 0–9.5 秒没有场景切换，只有真实滚动、摄像机推近和虹彩光带的形态交接。
- 9.5 秒进入品牌锁定时使用 0.55 秒 focus pull；feed 不消失。
- 精选瞬间允许 2 帧轻微曝光抬升和色散，不做全屏白闪。
- 不使用横向甩镜、卡片蒙太奇、黑场硬切或独立 logo 场景。

## 仿真页面要求

1. 1920×1080、X 深色模式，左侧导航、中央 feed、右侧趋势全部由 HTML/CSS 构成。
2. 帖子、头像、媒体卡和计数使用虚构数据，不读取真实账号或个人 feed。
3. 状态胶囊完整可见；分析数增长至少 6、精选数增长至少 1。
4. 至少一条命中内容完整经历：扫描 → 边框点亮 → 短词二次处理。
5. feed、精选边框和短词共用 DOM 坐标系，滚动时不能发生视觉脱节。
6. 不使用网页截图或屏幕录制作为底层画面。

## HyperFrames 实现约束

- HTML 是唯一画面源文件；音轨后续单独挂载。
- 整片只建立一个 12 秒主组合，四个 beat 是同一场景的状态，不拆成海报式子场景。
- GSAP 时间线必须暂停注册，所有运动可 seek、无无限循环、无 `Math.random()`。
- Thinking Orb 直接复用插件 Canvas2D 几何，并由主时间轴驱动；不得使用浏览器实时时钟。
- 先完成 0.0 / 2.6 / 5.2 / 10.8 秒英雄帧，再接入运动与声音。
